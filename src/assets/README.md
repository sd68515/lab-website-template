# 字体 / Fonts

`fonts/` 包含自托管的 Inter、Source Serif 和 Source Han 字体，以及各字体的许可证。`css/` 的 `@font-face` 与 `../styles/variables.scss` 中的字体族配合使用。更换或删除字体时，同时更新字体声明、变量和许可证说明。

`fonts/` contains the self-hosted Inter, Source Serif and Source Han fonts and their licenses. The `@font-face` rules in `css/` match the font stacks in `../styles/variables.scss`. When replacing or removing a font, update its declarations, variables and license notices together.
