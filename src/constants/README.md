# 主题颜色 / Theme colors

`appearance.ts` 分别定义浅色和深色主题的颜色。修改语义色时请成对检查文字、背景、边框及图表的可读性；CSS 变量映射位于 `../styles/variables.scss`。

`appearance.ts` defines the light and dark palettes. Check text, background, border and chart contrast together when editing semantic colors; CSS variable mappings are in `../styles/variables.scss`.
